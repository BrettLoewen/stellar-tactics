# stellar-tactics
A tactics game prototype in the style of XCOM

--Plans--<br>
--Phase 1--<br>
Overview: Create the foundations for future phases of development to build upon<br>
Features:
<br>    -Units with a small amount of primitive actions (move, shoot, grenade, melee, and interact)
<br>  -The foundations of a tile-based navigation system
<br>  -A simple gameplay loop consisting of one level where the goal is to kill all enemies before they kill all of the player's units
<br>  -A good amount of polish (animations, transitions, audio, and visual effects)
