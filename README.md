# Stellar Tactics

A tactics game prototype in the style of XCOM

### How to play

- Right-click to switch your selected troop
- Select the action you want that troop to perform
  - Actions: Move, Shoot, Grenade, Melee, and Interact
  - Each troop has 3 action points
  - Attacks cost 2 points, Move and Interact cost 1 point
- Left-click a target to perform the action
  - Examples: Tiles for moving, enemies for attacking, and doors for interacting
- Click the END TURN button to progress to the next round
- Defeat all enemies to win

#### Extra controls

- WASD/arrow keys to move the camera
- Mouse scroll wheel to zoom in/out
- Q/E to rotate the camera left/right
